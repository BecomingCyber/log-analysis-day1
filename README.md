## 🧪 Lab Projects

### ✅ Day 1: Introduction to Log Analysis

**Focus:** PowerShell Script Block Logging and Windows Event Viewer.

In this lab, I practiced identifying PowerShell activity using Event ID 4104.

The investigation examined the following command:

`Get-LocalUser | Select-Object Name, Enabled`

The event demonstrated how PowerShell logging can provide visibility into local account enumeration. I also documented why this activity alone does not establish malicious intent.

## 📚 Learning Approach

For each lab, my goal is to:

1. Understand the activity being investigated.
2. Examine the available logs and evidence.
3. Identify relevant security events.
4. Explain what the evidence supports.
5. Document the investigation and lessons learned.
